# Output Fixed Export Zone

Whenever an app from `/incoming_app/` is inspected, fixed, and verified in the live emulator, the clean, production-ready source code will be exported here.

### How to use:
1. Pull or copy the contents of `/output_fixed/` back into AndroidIDE on your phone.
2. Run `./gradlew assembleDebug` in AndroidIDE to build and test directly on your physical device.
