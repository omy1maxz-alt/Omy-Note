# Incoming App Drop Zone

Place your raw AndroidIDE project files, ZIP extractions, or Git branches into this directory (`/incoming_app/`).

### How to use:
1. Copy or push your Android project files into `/incoming_app/`.
2. Tell the AI: **"Inspect the app in incoming_app"** or **"Mount and run incoming_app in emulator"**.
3. The AI will analyze your manifest, Gradle files, dependencies, and code, fix any issues, and deploy the app to the live preview emulator.
